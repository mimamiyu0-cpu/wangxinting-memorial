摘要

针对传统红色基地导览系统普遍存在的开发部署架构偏重、公众互动形式单一以及缺乏用户行为数据量化分析能力等现实问题，本文设计并实现了一个基于 Express 与 SQLite 的轻量级红色基地互动导览系统——“王新亭将军红色教育基地线上导览系统”。系统后端基于 Node.js 平台与 Express 轻量级框架，配合轻量级嵌入式 SQLite 文件数据库，实现了零配置、低成本的高效云端部署。针对移动端多设备访问特征，系统创新性地采用 IP+UA 指纹生成无记名用户唯一标识，构建了无需注册登录的用户追踪与防重复提交机制。

系统前端采用 H5 移动网页形态，涵盖首页时间轴叙事、红色足迹地图、防重复打卡签到、献花致敬、知识答题、AI 导览助手、Canvas 荣誉证书生成等 11 个深度交互模块，并全面融入级联字号调节等适老化无障碍设计；PC 管理端则引入 Sankey 桑基图与 ECharts 图表，对参观者的行为路径与展点转化率进行深度量化追踪，通过数据反哺展馆常态化运营。实际部署与测试表明，该系统具有结构轻捷、交互沉浸感强、数据驱动精准等优势，有效提升了红色文化的数字传播效能，为中小型红色场馆的智慧博物馆建设提供了具有普适意义的轻量化工程范例。

关键词： 红色基地；互动导览系统；Express；SQLite；数据可视化

Abstract

To address the critical bottlenecks of heavy technical architectures, monotonous interaction paradigms, and the lack of quantitative data analysis in traditional red education base guiding systems, this thesis presents the design and implementation of a lightweight interactive guiding system based on Express and SQLite, specifically deployed as the "Online Guiding System for General Wang Xinting Red Education Base". The system seamlessly integrates the Node.js platform and Express framework with an embedded SQLite database to achieve a zero-configuration, cost-effective, and rapid deployment. To lower the operational friction for visitors while ensuring data security, a non-registration user tracking and anti-duplicate submission mechanism is developed by extracting unique user identifiers from synthesized IP and User-Agent fingerprints.

The mobile H5 client consists of 11 multi-dimensional functional modules, including a chronological life timeline, ECharts-based red footprint maps, anti-duplicate check-ins with star animations, virtual flower tributes, knowledge quizzes, a keyword-shunting AI guiding assistant, and Canvas-rendered honorary certificates. Simultaneously, age-friendly non-barrier optimization strategies, such as adaptive font-size cascade adjustments, are applied to mitigate cognitive loads for elderly groups. The PC administration platform introduces Sankey diagrams to map out the visualization of user behavior conversion paths and exhibit transformation rates, coupled with soft-deletion message moderation and CSV data utilities. Practical deployment proves that the proposed system stands out for its structural agility, immersive engagement, and data-driven feedback loops, successfully paving an innovative pathway for the digital preservation of red cultural heritage and the construction of participative smart museums.

Keywords: Red Base; Interactive Guiding System; Express; SQLite; Data Visualization

1 绪论

1.1 研究背景与意义

1.1.1 红色文化数字化转型的背景与必要性

红色文化是中国共产党领导中国人民在革命、建设和改革开放伟大实践中创造的宝贵精神财富。王新亭将军作为我军著名的军事家和政治工作领导者，其光辉的一生凝聚了坚定的革命信仰与崇高的革命理想。在新时代背景下，如何完整保护、深度发掘并广泛传播王新亭将军等革命先辈的红色事迹，成为爱国主义教育与思想政治建设的重要课题。

随着信息技术的迅猛发展和网络普及率的持续提升，传统的文化传播介质与大众的信息获取习惯发生了深刻的历史性转变，红色文化资源的数字化保护与创新发展已成为弘扬爱国主义精神、坚定文化自信的必然路径。将现代数字网络技术、交互多媒体技术与革命纪念馆的实体场馆深度融合，构建面向未来的“智慧博物馆”，不仅是打破物理空间和时间限制、拓宽红色文化辐射面与触达率的时代要求，更是推动文旅融合向纵深发展的新型趋势。在新媒体环境下，红色文化的数字传播不仅能够赋予历史文献和革命文物以全新的生命力，更在跨越时空局限的情境中重塑了价值引领的传播路径，对于拓展青年群体的思想政治教育阵地具有无可替代的现代价值。因此，面向红色教育基地建设集智慧交互、参观展示、教育普及于一体的数字化网络平台，是当前数字展馆建设和文旅信息化转型过程中最为紧迫的建设任务之一。  

1.1.2 传统红色基地导览存在的问题与解决切迫性

然而，审视当前我国多数中小型红色教育基地及革命纪念馆的数字化建设现状，普遍面临着形式滞后、架构臃肿、数据脱节等多重现实瓶颈，难以适应新时代公众对高品质数字文旅产品的切实期望。其核心痛点主要体现在以下三个维度：

首先，数字化互动的深度与沉浸感严重不足。多数景点的数字技术应用仍停留在表层的“静态图文搬网”或简单的“复刻版展板”形态，在交互体验与情感共鸣的设计上缺乏系统性的考量，导致观众在浏览过程中处于被动的“信息接受者”角色，极易产生视觉与心理上的审美疲劳。从数字导览的用户体验与感知维度来看，由于缺乏对受众心理、行为特征及界面交互感知要素的深度挖掘，现有的诸多导览界面无法有效建立起观众与红色历史场景之间的深层情感投射。

其次，技术方案普遍偏重，缺乏面向中小型红色基地的普适性。在已有的数字博物馆或智慧旅游平台实践中，开发者往往倾向于采用高度企业化的重型技术架构。例如，部分大型项目依托于复杂的 Java 与 HTML5 混合体系进行数字化开发，或者基于 Spring Boot 微服务与 Vue 渐进式框架构建全栈式的智慧旅游平台。这类重型方案虽然功能齐备，但其背后伴随着冗长的依赖链条、苛刻的服务器硬件配置、高昂的商业授权或云资源开销，以及极高的常态化 IT 运维门槛。对于绝大多数缺乏专业技术编制、预算有限的中小型红色基地而言，这种“重架构”方案具有极高的落地阻力与维护成本，导致大量宝贵的红色基地在线上数字化浪潮中因技术和资金壁垒而陷入停滞。

最后，系统普遍缺乏后端数据采集与量化行为分析的能力。现有的线上导览多表现为纯前端的 H5 页面或孤立的全景智能展示系统，其功能设计往往呈现“重前端渲染、轻后端统计”的失衡状态，普遍缺乏对用户访问轨迹、动态交互行为的精准追踪与持久化留存机制。由于无法精确捕捉页面访问量（PV）、独立访客数（UV）以及观众在不同展区之间的跳转流向与留存时长，管理人员无法获得科学、量化的运营反馈，导致数据资产长期处于荒废状态，线下场馆的陈列优化与线上系统的迭代也因缺乏“数据反哺”而沦为凭经验决策。  

上述三大问题的重叠并存，严重制约了红色文化在互联网时代的传播效能，证明了研发一套兼具轻量化部署、高沉浸互动与深度数据驱动特征的新型互动导览系统，具有极其迫切的现实意义与工程价值。

1.1.3 本文提出的解决方案与系统特征

针对上述传统红色导览系统在交互体验、技术成本和数据反哺等层面的结构性缺失，本文立足于轻量化文旅数字化转型的研发视角，设计并实现了一套基于 Node.js Express 框架与 SQLite 嵌入式数据库的“王新亭将军红色教育基地线上导览系统”。本系统旨在通过创新的工程架构与多维度的功能矩阵，为中小型革命场馆提供一种低阻力、高成效的数字化建设样范。系统具备以下核心特征：

轻量级与零配置部署：系统后端采用事件驱动、非阻塞 I/O 的 Node.js 平台，配合极其精简的 Express 路由控制层，免去了传统企业级中间件繁杂的配置流程。数据库选用轻量级、无独立常驻服务进程的 SQLite 单文件数据库，通过在后端执行自定义的 Promise 异步化封装，完美融合 异步控制流，在极低计算资源的单核云服务器上即可实现敏捷、平稳的高并发路由分发与事务处理。同时，系统创新性地利用客户端 IP 与客户端浏览器 User-Agent 复合指纹生成 MD5 哈希编码，在免除观众繁琐的注册登录成本的同时，在无状态的 H5 场景下建立起了鲁棒的无记名用户追踪与防重复提交打卡机制。

丰富的多维交互矩阵：前端打破了单向阅读的枯燥模式，设计实现了包含生平时间轴叙事、基于 ECharts 的将军红色足迹可视化地图、基于时效窗口与数据库联合约束的防刷打卡签到、飘落花瓣特效的线上献花致敬、以及带有即时评分与耗时度量的知识答题等 11 个交互模块。系统利用 Canvas 绘图技术，在移动端本地动态绘制带有用户专属昵称、答题成绩及系统动态二维码的荣誉证书与成就海报，极大地激发了参观者的社会化分享与自传播意愿，使观众从“被动参观”向“深度参与”发生历史性转变。

精准的数据驱动决策:P C 端管理后台引入了先进的用户行为路径追踪技术，通过跨表会话提取，利用 ECharts 及 Sankey（桑基图）可视化组件，具象化地描绘出参观者从首页进入、流向特定展点、触发互动直至留言流失的完整行为转化图谱。这一极具反哺价值的看板功能，使管理人员能够精确掌握每一个展点的用户留存率与知识转化率，从而为线下展区的陈列优化和爱国主义教育路径的调整提供精准的定量数据支撑。

彻底的适老化无障碍关怀：针对红色基地受众中中老年群体占比较高的现实特征，系统在视觉传达与交互触点上实施了深度无障碍干预。利用  状态持久化技术，设计了支持全局级联响应的字号大小调节组件与全局语音讲解功能，配合大于 44px 的高对比度触控热区，显著降低了中老年群体的认知与操作负载，真正实现了红色文化数字化传播的包容性与普适性。

综上所述，本系统的研制不仅成功解决了王新亭将军红色教育基地线上数字化传播的工程现实问题，更为我国大量面临技术与资金双重制约的中小型爱国主义教育基地，提供了一条低成本、高复用、数据闭环的智慧博物馆创新建设路径。

1.2 国内外研究现状

1.2.1 国外研究现状

在国际博物馆信息化与数字文旅研究领域，数字导览系统的研发与应用经历了一段从“基于特定硬件的单向语音播报”向“基于移动互联网的双向智能交互”演进的技术历程。伴随着人机交互（HCI）技术与数字博物馆学的交融，国外学者针对数字导览对观众行为的量化影响、界面感知的评估因素以及博物馆角色范式的转变展开了大量实证研究与理论构建，为现代智慧文旅系统的研发提供了系统化的方法论支撑。

首先，在数字导览对观众行为及参观成效的定量化研究方面，国外学术界建立了较为完善的实验观察与行为追踪机制。Eghbal-Azar 等人聚焦于数字化导览介质对展厅内观众信息选择与留存行为的干预效应，展开了深度的实证行为学研究。该研究巧妙运用眼动追踪与空间轨迹分析等实证方法，系统探讨了数字导览系统在博物馆展厅中的决定性影响。其核心研究成果明确指出，相比于传统无导览或纯纸质导览的参观模式，在展厅中合理引入并使用数字导览系统的观众，其在特定展览区域和个体展品前的常态化停留时间能够显著延长约 60%。同时，数字化交互手段能够引导观众对个体的历史文物或艺术展品展开更为深入、细腻的审视与认知，而非走马观花式的浅层浏览。这一量化结论有力证明了数字导览在延展观众注意力周期、深化信息接触深度方面的核心价值，也为本系统在后端引入答题计时（time_cost）与打卡留存等行为追踪模块提供了坚实的实证心理学依据。  

其次，在数字导览系统的用户体验（UX）与交互感知层面，国外研究逐渐由早期的功能性测试转变为多维度的认知感知评估。Chang 与 Wu-Haw 深入探究了博物馆数字导览系统的用户体验与感知逻辑，致力于解决数字界面与场馆物理空间对冲所带来的认知摩擦问题。他们创新性地引入了质量管理与心理学交叉的 KJ 法（亲和图法）以及具有高度专家共识性的德尔菲法（Delphi Method），对大量导览系统的交互触点进行了多轮归纳与提炼，从而成功构建了一个包含多层次感知维度的数字导览系统用户体验评估因素框架。该框架强调，数字导览系统的界面可用性、反馈即时性、认知负载最小化以及情感共鸣度，是决定数字导览能否成功转化为知识传播效能的核心决定因素。这一研究为数字导览系统的界面架构设计确立了规范化的工程指引，也启示了本系统在面对中老年群体或特定高频交互场景时，必须引入低认知负载的适老化字号调节以及高响应力的即时视觉反馈机制。  

此外，国外数字导览技术的研究并非孤立存在，而是深深根植于现代博物馆学理论的范式变革之中。常丹婧从现代博物馆功能转型的宏观视角出发，系统梳理了国际博物馆界从传统的静态“参观”向动态“参与”的历史性转向，全面阐述了“参与式博物馆（The Participatory Museum）”的核心理论内涵与观众参与的必然趋向。这一理论彻底打破了过去展馆作为“权威知识灌输者”的绝对中心地位，主张通过数字中介重构一种民主化、去中心化的双向对话机制，将观众转变为历史情境的共同构建者与文化意义的积极生产者的角色。在这一参与式理论的实践延展上，崔子玥通过具体的博物馆观众参与实践案例，深入剖析了互动机制在引发观众情感投射和价值认同层面的核心价值。该研究以具体的艺术展为例，论证了通过系统性的动态机制设计引导观众进行身体和情感上的深度互动，能够成功激活观众的自主思考，使静态的历史陈列在参与者的个体经验中产生强烈的情感共鸣与价值认同，从而完成深刻的精神洗礼与教育闭环。这些关于“参与机制”与“情感投射”的理论探索，直接赋予了本系统打卡签到、献花致敬、黑板风格留言等高粘性交互模块以深刻的 museology（博物馆学）合法性。

然而，纵观国外在智慧博物馆与数字导览领域的现有研究成果，尽管其在量化行为分析、用户体验评估因素以及参与式交互理论等层面已表现出极高的成熟度，但将其直接移植并应用于我国中小型红色教育基地时，依然存在明显的场景错配与技术应用壁垒。一方面，国外的实证案例与评估模型多建构于西方大型美术馆、自然历史博物馆或商业性文化展馆的语境之下，在功能规划与叙事逻辑上，本质上缺乏针对“红色文化传承、革命先辈事迹弘扬、思想政治价值引领”这种高政治性、高严肃性且富有特定情感张力的革命教育场景的专项设计。另一方面，国外诸多前沿数字系统在工程落地时，往往极度依赖昂贵的高带宽本地基站、繁重的 Native APP 应用或者基于高算力的云端重型框架，这与我国区域性中小型革命纪念馆在实际常态化运营中所面临的预算受限、技术编制缺乏、需要“零配置、极轻量、跨平台免安装即开即用”的工程现实诉求产生了严重的脱节。这种国际研究中“重型商业方案成熟，而轻量化红色政治场景专项设计缺失”的学术与工程断层，正是本文研究并开发基于 Express 与 SQLite 的轻量级红色基地互动导览系统的核心切入点与学术生长点。

1.2 国内外研究现状

1.2.2 国内研究现状

近年来，随着“智慧文旅”与“智慧博物馆”概念在国内的全面普及，国内学者及工程技术人员针对红色文化资源与数字化交互技术的融合进行了大量探索。国内的研究路径主要聚焦于高并发企业级架构的应用、三维全景导览的构建以及移动端H5交互设计的优化。然而，在面对中小型红色教育基地的具体工程落地时，现有研究方案在架构轻量化、互动深度及数据反哺能力上仍存在不同程度的局限性。以下对国内代表性的研究成果进行梳理与对比分析：

（1）马自萍等人的数字博物馆系统研究

研究内容：马自萍等人设计并实现了一个基于 Java 与 HTML5 技术的数字博物馆系统。该系统利用 Java 语言稳健的后端处理能力与 HTML5 灵活的前端渲染特性，对地方特色馆藏文物进行了结构化数据存储与线上多媒体展示，初步实现了馆藏资源的数字化迁移。  

存在不足：该方案采用了典型的 Java 企业级重型开发模式（如 SSM 或 SSH 架构），此类架构包含繁琐的 XML 配置文件、多层级 Bean 对象的装配以及对 Tomcat 等独立应用服务器的强依赖。这不仅拉长了开发周期，更带来了苛刻的运行时内存与计算资源开销。对于缺乏专业技术团队和常态化 IT 预算的中小型红色教育基地而言，该方案的部署、配置与常态化运维门槛过高。

与本文对比：本文系统在后端弃用了臃肿的 Java 体系，改用事件驱动、非阻塞 I/O 的 Node.js 平台与轻量级 Express 框架，配合无须独立运行进程的嵌入式 SQLite 文件数据库。该工程方案极大地精简了依赖链条，在单核 CPU、1G 内存的低配置云服务器上即可实现“零配置”敏捷部署，从根本上降低了中小型场馆的数字化建设门槛。

（2）肖程鸣等人的红色智慧旅游平台设计

研究内容：肖程鸣等人针对红色文旅场景，开发了基于 Spring Boot 后端微服务框架与 Vue 渐进式前端框架的红色智慧旅游平台。系统实现了红色旅游路线规划、展区内容动态发布以及基础的管理端维护功能，是国内红色文旅数字化转型的典型实践。  

存在不足：该系统由于引入了 Spring Boot 与 Vue 的全栈分离重型架构，在生产环境中往往需要依赖 Docker 容器化编排、Nginx 反向代理服务以及独立的 JVM 内存调优。这种“重架构”方案在小型单体基地应用时存在严重的“技术过剩”问题，高额的服务器带宽及硬件购置成本限制了其向基层场馆的普适性推广。

与本文对比：本文方案推崇“结构瘦身”与“轻量触达”，前端放弃了复杂的单页面应用（SPA）状态机管理，采用轻量化、模块化的原生 H5 技术栈;后端利用 Express 实现静态资源托管与 RESTful API 的一体化集成。观众通过手机微信扫描现场二维码即可秒级唤起系统，无须下载安装，完美兼顾了运行性能与部署的经济性。

（3）朱中一的全景智能导览系统研发

研究内容：朱中一设计并实现了博物馆全景智能导览系统，该研究侧重于全景视觉渲染技术的应用。系统通过高清全景照片的拼接与 3D 虚拟空间的搭建，为线上用户提供了一种足不出户即可在虚拟展厅中进行空间漫游与视觉导航的沉浸式体验。  

存在不足：该系统表现出重“视觉呈现”、轻“后端量化”的失衡倾向。系统虽然提供了精美的三维视觉效果，但忽略了对用户在漫游过程中底层交互数据的采集与持久化沉淀，缺乏对观众行为路径、停留时长以及交互热点的量化分析能力，无法为展馆的常态化运营提供科学的数据支撑。

与本文对比：本文系统在保障优质图文与音频导览的同时，将研发重心向“数据驱动”倾斜。系统在管理端深度集成了基于 ECharts 和 Sankey（桑基图）的用户行为路径分析模块。通过对无记名会话（session_id）下的页面流转轨迹进行跨表聚合分析，量化追踪展点转化率与跳出率，实现了真正的数字化数据反哺运营。

（4）曾憧杰的移动端数字博物馆交互设计研究

研究内容：曾憧杰从人机交互（HCI）与工业设计视角出发，深入探讨了基于移动端的数字博物馆交互设计方法。该研究细致规划了小屏幕视图下的 UI/UX 布局原则、手势操作映射机制以及信息架构的扁平化策略，为移动端导览界面的视觉重构提供了方法论指导。  

存在不足：该研究本质上属于偏向前端的视觉与交互概念设计，未能构建起一个包含完整后端状态持久化与跨端数据同步的闭环软件实体。当面临多设备切换、离线数据校验或者高频防刷打卡等复杂的后端业务逻辑时，该理论模型缺乏相应的工程技术方案支持。

与本文对比：本文是一项前后端协同的完整软件工程实践。不仅在前端落地了曾憧杰所提倡的扁平化高效交互，更在后端构建了坚实的数据管理层。针对参观者可能在多设备或多时间段访问的场景，创新设计了前端 localStorage 与服务器 SQLite 数据库的最高分智能合并算法，实现了数据在无状态 H5 环境下的高鲁棒性同步。

（5）黄小真的 H5 旅游导览设计探索

研究内容：黄小真立足于文旅融合的宏观视角，对特定文化街区的 H5 旅游导览系统进行了设计与研究。系统利用 H5 的跨平台多端适配优势，设计了流畅的移动端信息浏览界面与区域性导览导向服务。  

存在不足：该方案在技术实现上呈现出“纯前端静态化”的局限。由于缺乏健全的后端分布式鉴权与关联存储机制，系统无法有效支持防重复打卡、在线知识答题排行榜动态排序、留言状态机审核等深度交互业务。其本质上仍是一个移动端的多媒体宣传册，缺乏双向交互的纵深。

与本文对比：本文系统依托于 Express 路由控制，建立了严密的数据双向交互网络。前端的所有核心交互行为（打卡、献花、答题）均通过高性能 API 异步提交至后端，在业务层施加多级去重校验，在数据库层设置联合唯一约束，从而将碎片化的前端触碰真正转化为安全、结构化的后台数据资产。

（6）崔嘉俊等人的红色文化数字化传承服务平台

研究内容：崔嘉俊等人设计并实现了一个面向红色文化传承的数字化服务平台。该平台围绕红色历史档案的规范化分类与数字化展示展开，构建了相对完整的革命史料数字仓库，对红色资源的线上留存具有积极贡献。

存在不足：该系统的业务逻辑设计相对传统，依然局限于“管理人员发布内容——参观者被动阅读”的线性传播范式。系统提供给普通参观者的互动功能较为单一，缺乏诸如答题激励、社交荣誉勋章以及适老化无障碍等深层服务设计，难以在青年群体或中老年群体中引发自发性的传播与深度共鸣。

与本文对比：本文系统构建了极为丰满的“参观者互动深度参与矩阵”。除了基础导览外，还拓展出含有星空Canvas庆祝动画的打卡、花瓣全屏飘落的致敬献花、融合多重算法模型的知识答题排行榜、AI 导览助手等 11 个交互模块。同时，通过 Canvas 动态绘制专属荣誉证书支持社交分享，并全面引入适老化级联字号调节，极大地丰富了受众的行为体验。

（7）章韵如的数字交互技术导览框架

研究内容：章韵如在深入研究数字交互技术的基础上，提出了红色文化景区导览系统的“知识组织—情境叙事—数字交互”三维体系框架。该研究从理论高度论证了数字技术在激活革命精神内核、重塑时空叙事结构层面的可行性路径。

存在不足：该项研究成果目前仍停留在宏观的理论框架构建与顶层概念设计阶段。由于缺乏具体的软件源码构建、数据库关系模式设计以及在真实环境下的黑盒与性能测试验证，其理论框架在面对高并发、高可用等工程现实约束时的有效性尚待检验。

与本文对比：本文系统是对章韵如所提理论框架的一次彻底的“工程化落地”与技术验证。本研究不仅完整实现了王新亭将军红色教育基地的线上导览软件系统，更针对实际运行中的技术瓶颈（如基于 IP+UA 复合指纹的无登录用户追踪、留言墙状态机的软删除机制等）出具了具体的代码级解决方案，并通过多组严密的表格化测试用例证明了该系统的工程应用价值。

1.2.3 国内外研究现状小结

纵观国内外数字导览与智慧博物馆领域的研究成果，学者与工程技术人员在受众行为量化追踪、交互体验因素评估以及数字化场馆情境构建等方面已取得了丰硕成果，为数字文旅的发展奠定了扎实的理论与工程基础。然而，将现有研究成果直接应用于我国中小型红色教育基地时，依然存在明显的结构性缺失，主要体现在以下三个维度：

技术架构普遍偏重
：现有主流方案过度依赖基于 Java 或 Spring Boot 的重型企业级分布式架构，不仅研发周期漫长、依赖链条复杂，且对服务器硬件算力与中后期常态化 IT 运维编制要求极为严苛，导致预算与技术编制匮乏的中小型革命场馆面临难以逾越的落地门槛。

互动功能纵深不足
：多数导览系统在业务设计上仍流于静态图文或音频的单向线性陈列，流于表层的“展板数字化”，缺乏能够引导观众身体参与和情感投射的深层双向交互机制，且普遍忽略了红色基地受众中高频出现的中老年群体，缺乏针对性的适老化无障碍服务设计。

数据分析链条脱节
：现有项目呈现明显的“重前端渲染、轻后端量化”的失衡局限，缺乏对无状态 Web 环境下用户唯一标识的鲁棒识别手段，无法精确追踪、持久化沉淀并具象化分析观众在不同展区之间的跳转轨迹与留存时长，难以实现数据反哺常态化运营的闭环。

鉴于此，本文立足于“轻量触达、深度参与、数据驱动”的研发视角，设计并实现了一套基于 Express 与 SQLite 的轻量级红色基地互动导览系统。系统通过创新的复合指纹免登录追踪算法降低访问摩擦，依托 11 个高粘性移动端模块深化多维交互，并引入基于 Sankey 桑基图的可视化看板精准量化参观者行为路径，从而为我国中小型革命场馆的智慧博物馆建设提供了一条兼具经济性与效能性的数字化创新范式。
